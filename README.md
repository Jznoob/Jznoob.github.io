# Hannn — Personal Homepage

A lightweight, bilingual personal research & engineering homepage hosted on GitHub Pages.

**Website:** https://jznoob.github.io/

## Features

- Responsive desktop and mobile layouts
- English / 中文 language switch
- Light / dark appearance
- Research, projects, honors and contact sections
- No build process or package dependencies

## Edit

Update `index.html` for the page content, `styles.css` for the design, and `script.js` for translations and interactivity. All public project links point to GitHub repositories.

## Publish with GitHub Pages

In **Settings → Pages**, set **Source: Deploy from a branch**, **Branch: main**, **Folder: / (root)**, and save. GitHub Pages will publish this user repository at https://jznoob.github.io/.

## Notes

The site intentionally does not claim unverified paper publication, provide an invented email address, or link to private repositories.
